# Baralai High School Management System

Baralai High School Management System is a responsive web-based school management project built with HTML, CSS, JavaScript, and Supabase. The project includes both a public website and a secure admin panel for managing students, teachers, staff, notices, results, and dashboard analytics.

## Features

- Public school website
- Admin login system
- Student add, edit, delete, and search
- Teacher and staff management
- Subject-wise result management
- Result publishing system
- Public result checking page
- Notices management
- Dashboard analytics
- Dynamic exam year support
- Supabase database integration
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Supabase
- Font Awesome
- Responsive Web Design

## Project Status

This project is under active development and designed for managing academic and administrative activities of Baralai High School.
